# IceBrkn: relationship memory for Meta glasses

Built during the Meta hackathon, Oct 26 - Nov 4 2026.

> "There's Sarah. Catch me up."
> IceBrkn remembers the little things about the people you know, and brings them back at the right moment.

This repo holds only the work built during the hackathon: the new modules, a fictional seed, and this README.
The IceBrkn app those modules plug into is an existing, live product (see "Existing vs new" below).

## Status

Building. Sections below fill in as each piece is built and proven.

## Meta models and tools used

| Meta model / tool | Where we use it |
|---|---|
| Muse Spark 1.3 (Meta Model API) | Reads photos, pulls out commitments, drafts the intro |
| Muse Voice Transcribe | Turns a voice note to Noa into text |
| Meta Wearables Device Access Toolkit | Glasses capture and playback |
| Muse Code | Used to build parts of this repo (marked per module below) |
